# AtlasTunnel v5

📡 Разворачивает и обслуживает VPN-сервер на Ubuntu одним статическим бинарником:
без зависимостей, с транзакционной установкой и откатом, TUI-менеджером и
неинтерактивным режимом для автоматизации.

---

## О проекте

Поднять VPN-сервер вручную — это апт-пакеты трёх разных протоколов, конфиги,
которые тихо конфликтуют друг с другом, и никакой уверенности, что через
полгода всё ещё работает так, как задумано. AtlasTunnel закрывает именно это:

- ставит и настраивает до **7 VPN-протоколов** на выбор, по отдельности или
  совместимым набором;
- откатывает **любую** неудачную установку до последнего рабочего состояния —
  ничего не остаётся в наполовину настроенном виде;
- сверяет заявленное состояние с фактическим (`atlas doctor`): конфиги,
  службы, учётные записи, правила iptables;
- одинаково удобен как TUI (`atlas`) для разового разворачивания руками и как
  CLI с `--json` для Ansible, cloud-init и CI.

## Протоколы

| Протокол | Шифрование | Рекомендация |
|---|---|---|
| **IKEv2/IPsec** | AES-256 | Основной выбор: быстрый, современный, переживает смену сети на телефоне |
| **SSTP** | TLS | Когда провайдер режет VPN — неотличим от обычного HTTPS |
| **OpenVPN** | AES-256-GCM | Максимальная совместимость, готовый файл профиля |
| **L2TP/IPsec** | AES-256 + PSK | Старые устройства без поддержки IKEv2 |
| **PPTP** | MPPE-128 | Только если ничего другого не поддерживается |
| **L2TP** | нет | Трафик открытым текстом — только для доверенной сети |
| **IKEv2** | null cipher | Без шифрования, ради скорости |

Подробное сравнение, ограничения по протоколам и что с чем несовместимо — в
[руководстве пользователя](docs/USER-GUIDE.md#какой-протокол-выбрать).

## Быстрый старт

На сервере под root:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Ground-Zerro/AtlasTunnel/main/install.sh)
```

По завершении будут выведены IP сервера, логин и пароль (и PSK/CA-сертификат,
если нужны) — с ними подключаются клиенты. Инструкции по каждому протоколу и
каждой ОС — в руководстве пользователя.

## Требования

- Ubuntu 22.04+ с systemd, права root
- Публичный IPv4-адрес — без него не заработают IKEv2, SSTP и OpenVPN
